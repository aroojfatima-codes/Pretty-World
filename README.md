## 🎀 Features & Highlights

- **Aesthetic Visual Design:**
  - Soft pastel palette: baby pink, blush, lavender, cream, and warm peach.
  - Ambient glowing background mesh orbs and floating decorative shapes (sparkles, flowers, hearts, ribbons).
  - Elegant typography featuring Google Fonts: *Playfair Display*, *Poppins*, and *Alex Brush*.
  - Layered soft shadows and modern glassmorphic frosted cards.

- **Interactive Sections:**
  1. **Navbar:** Fixed frosted header on scroll, active section highlight, and animated mobile slide drawer.
  2. **Hero:** Catchy headline, floating affirmation badges, call-to-action buttons, and floating particles.
  3. **About:** 4 philosophy cards highlighting Self-Love, Confidence, Creativity, and Positive Radiance.
  4. **Lifestyle Pillars:** 4 cards (Beauty & Skincare, Fashion & Style, Self-Care & Wellness, Dreams & Goals) with interactive detail popups.
  5. **Pinterest Moodboard Gallery:** Masonry-style layout, category filter tabs, interactive like counters with heart pop animation, and full-screen lightbox preview.
  6. **Daily Inspiration:** Random motivational quote generator with smooth transitions and 1-click clipboard copy with toast feedback.
  7. **Contact:** Interactive form with real-time validation (name, email, message length) and animated celebration success modal.
  8. **Footer:** Brand bio, quick links, category pillars, newsletter subscription with email validation, sweet motto banner, and smooth back-to-top floating button.

## 🚀 Running Locally

No installation or dependencies required! You can run this website using any of the following:

### Option 1: Python
```bash
python -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.

### Option 2: Node.js
```bash
npx serve .
```

### Option 3: Direct Browser Launch
Simply double-click `index.html` or open it with any web browser.
